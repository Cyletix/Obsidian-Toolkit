# Obsidian Toolkit

我为 Obsidian 编写的插件与脚本合集索引。各项目在各自仓库独立开发与发布，本仓库只做导航。

| 项目 | 类型 | 说明 | 最新版本 |
|---|---|---|---|
| [Lock-Bases-View](https://github.com/Cyletix/Lock-Bases-View) | 社区插件 | 锁定 Bases 视图，防止误编辑 | ![](https://img.shields.io/github/v/release/Cyletix/Lock-Bases-View) |
| [MemoFlow](https://github.com/Cyletix/MemoFlow) | DataviewJS 脚本 | 类 Thino 的费曼笔记输入框与任务视图 | ![](https://img.shields.io/github/v/release/Cyletix/MemoFlow) |
| [QuickAddScript](https://github.com/Cyletix/QuickAddScript) | QuickAdd 脚本 | 文本处理宏：格式转换、清理、数学公式处理等 | — |

## 一键克隆全部

```powershell
./clone-all.ps1            # 克隆到当前目录
./clone-all.ps1 -Dest D:\GitHub
```

已存在的仓库会执行 `git pull` 更新。
